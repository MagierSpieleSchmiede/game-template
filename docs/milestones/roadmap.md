# Roadmap & milestones — what comes when

| Milestone | Scope | Status |
| --- | --- | --- |
| M0 — Template | This repository: simulation skeleton, vault, CI, deploy | done |
| M1 — Prototype | The game's fundamental loop: units, movement, one ability, win condition; determinism test green at all times | planned |
| M2 — Presentation | Camera, HUD, localisation, input mapping, sound | planned |
| M3 — Netcode | Rollback with server as referee, first PvP | planned |
| M4 — Beyond | AI/RL, add-ons, creatures, large world — see [[extension-points|Extension points]] | planned |

Each milestone has an implementation log (`m1-implementation-log.md`, created when M1 starts): what was built, in which order, with which decisions. The current work is always in [[status|Status]] and [[backlog|Backlog]].
