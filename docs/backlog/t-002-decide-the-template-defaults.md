# T-002 — Decide every template default: accept, replace or drop

**Status:** open · **Scope:** game · **Depends on:** [[t-001-adapt-the-template|T-001]]

**Read for that:** [[decisions|Decisions]], ADR-0012

**What:** Go through every ADR with status `default` (ADR-0006, 0013–0017). For each, accept it, replace it with a new ADR, or drop it, following its *To replace* section.

**Done when:** No ADR has status `default` any more.
